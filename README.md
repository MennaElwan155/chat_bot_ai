# 🤖 AI Chatbot App

A modern, responsive AI-powered chat application built with Flutter. It provides an intuitive conversational interface, seamless interaction, and a sleek user experience.

---

## ✨ Features

- 💬 **Interactive AI Chat:** Real-time conversational interface.
- 💡 **Ideas & Prompts:** Quick suggestions and topics to spark conversations.
- ⭐ **Favorites & History:** Easily save important messages and browse past interactions.
- 🎨 **Modern Dark UI:** Beautiful aesthetics with smooth gradients and custom typography.
- ⚙️ **Settings & Customization:** Personalized user experience with profile and feedback management.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **Architecture:** Clean component-driven UI structure (`screens`, `widgets`)
